# Bark 3.0 Pro local model option

Requested: add Bark alongside the existing local choices. Preserve the user's selected model (Parakeet Ultra).

## Implementation

- Mac catalog entry: `bark-3.0-pro`, English only, 1,234,604,822 download bytes including vocabulary, licenses and attribution.
- Publisher: [Conway Research](https://huggingface.co/ConwayResearch/Underdog-Bark-3.0-Pro), revision `d87f288a9a0b0cdb92228057e168ce575b300a6b`. All 16 downloaded files are checked against pinned SHA-256 values before loading.
- The model card states CC BY-NC 4.0. Both UI languages say noncommercial use only. The download includes the original LICENSE, upstream CC-BY license and NOTICE.
- Uses the existing FluidAudio 0.17.3 dependency, the publisher's CoreML frontend/decoder/joint and `full15` encoder function. Encoder runs on CPU/Neural Engine; the other components on CPU. Recordings retain FluidAudio's long-form handling and fresh decoder state per dictation. No cleanup model is added.
- Apple silicon and macOS 15 minimum, shown as unavailable on Intel or older macOS. Windows/Linux do not offer this CoreML build because their existing runtimes cannot run it.
- Compiled models are cached beneath the model's pinned revision directory. The cache stays with the model when moved to Trash. A read-only test copy cannot create that cache in the user's model folder.
- No automatic download or preference migration was added. Download, selection, progress, cancellation, speed measurement and removal use the existing local-model flow.
